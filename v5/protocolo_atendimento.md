## 3. FLUXO DE ATENDIMENTO

### 3.1 Primeiro Contato (Lead)

**Gatilho:** Cliente envia mensagem inicial (geralmente "Qual o valor?" ou "Gostaria de ver modelos")

**Resposta automática padrão:**
```
Olá! O valor está à partir de R$60,00

Confira os modelos e faça o orçamento AGORA MESMO através do nosso site!
🌐 Nosso site 👉 https://convites.mforge.com.br/home/orcamento
Depois de pagar o sinal, clique em "enviar"!

Se preferir fazer o orçamento pelo whatsapp, aguarde que vamos te responder!
```

**Se cliente preferir WhatsApp:** Solicitar cores e tema desejados, enviar modelo similar.

### 3.2 Apresentação de Modelo

1. Enviar link de modelo similar ao desejado
2. Explicar diferença entre Abertura Curta (R$60) e Longa (R$85)
3. Responder dúvidas sobre personalizações

**Frase modelo:**
```
Esse modelo que te enviei possui a *Abertura Longa* (Esses vídeos e frases passando na tela), portanto fica *R$85*

Caso queira com a *Abertura Padrão* (O envelope abre igual no vídeo, mas em seguida já aparece o convite com os dados e botões), fica *R$60*
```

### 3.3 Fechamento do Pedido

1. Solicitar sinal de R$20 ou pagamento integral
2. Coletar dados do evento (ver seção 4)
3. Confirmar entrada na Fila de Produção
4. Informar previsão de entrega

**Frase modelo:**
```
Trabalhamos com sinal de R$20, e o restante só depois que entregarmos o convite pronto e você aprovar!
```

### 3.4 Produção

1. Enviar prévias parciais para aprovação (envelope, bonequinha, cores)
2. Solicitar ajustes se necessário
3. Entregar convite completo
4. Solicitar verificação de todos os dados

**Frase de entrega:**
```
Você acaba de receber um *Convite Especial!* ✉️✨

Acesse o link para abrir 👇

[LINK DO CONVITE]
```

### 3.5 Finalização

1. Confirmar aprovação do cliente
2. Solicitar pagamento do restante
3. Remover aviso de "Pagamento Pendente"
4. Enviar link da planilha (se tiver formulário)
5. Oferecer cupom de desconto (15% OFF)

**Frase modelo:**
```
Se estiver tudo certinho, podemos finalizar o seu atendimento com o pagamento do restante para que eu possa remover o aviso de pagamento pendente!

Ainda que encerremos o atendimento, você pode vir pedir alguma correção caso encontre algum erro que passou despercebido, tá bom?
```

## 5. RESPOSTAS PARA PERGUNTAS FREQUENTES (FAQs)

### 5.1 Sobre o Produto

| Pergunta | Resposta |
|----------|----------|
| "Vem em PDF?" | Não, o convite é um link (site) porque PDF não suporta vídeo e música. Podemos fazer arte para impressão separada (+R$25). |
| "É R$60 por convite/pessoa?" | Não, R$60 é pelo serviço de criação. Você recebe um link e pode enviar para quantas pessoas quiser, sem limite! |
| "Quantas fotos posso colocar?" | Até 15-20 fotos no convite |
| "O link dura quanto tempo?" | Hospedado no Github, não removemos do ar. Ficará online "pra sempre"! |
| "Posso alterar depois de pronto?" | Sim! Mesmo após finalizar, você pode voltar para pedir correções |
| "Se alguém encaminhar o convite, outra pessoa pode confirmar?" | Sim, mas você receberá a confirmação no seu WhatsApp e poderá controlar |

### 5.2 Sobre Pagamento

| Pergunta | Resposta |
|----------|----------|
| "Como funciona o pagamento?" | Sinal de R$20 para entrar na fila, restante após aprovar o convite pronto. Aceitamos Pix e cartão! |
| "Posso pagar integral?" | Sim, sem problemas! |

### 5.3 Sobre Funções

| Pergunta | Resposta |
|----------|----------|
| "Qual a diferença do Formulário para WhatsApp?" | WhatsApp (grátis) recebe confirmações diretas. Formulário (+R$5/15) organiza tudo numa planilha Google automática |
| "A Lista de Presentes confirma compra?" | Não temos como confirmar, o dinheiro vai direto pro seu Pix |
| "Posso colocar lista de loja (Magalu, Shein)?" | Sim! Você cria a lista no site da loja e nos envia o link. Nesse caso não cobra adicional |

### 5.4 Técnicas

| Problema | Solução |
|----------|---------|
| Música não toca (iPhone) | Problema do navegador da Apple. Precisa clicar para interagir antes da música tocar |
| Convidado vê versão antiga | Limpar cache ou testar em outro aparelho. A versão online é sempre a atual |
| Folha não abre (iPhone) | Problema conhecido em alguns iPhones, pode requerer ajuste técnico |

## 6. CENÁRIOS ESPECIAIS

### 6.1 Cliente Indeciso entre Curta e Longa
- Enviar modelo de cada tipo para comparação
- Explicar claramente a diferença visual
- Não pressionar, deixar cliente decidir

### 6.2 Festa de Gêmeas/Dupla
- Fazer duas seções de sugestão de presentes com Pix diferentes
- Manter tudo no mesmo convite

### 6.3 Evento Muito Distante (meses)
- Cronômetro regressivo funciona automaticamente
- Alterações podem ser feitas a qualquer momento até a data

### 6.4 Cliente Muda de Ideia (mãe vs filha)
- Comum! Ser paciente e flexível
- Confirmar alterações antes de prosseguir
- "Sem problemas, podemos alterar!"

### 6.5 Solicitação de Urgência
```
Posso colocar o seu com prioridade pra te entregar ainda hoje até [HORÁRIO]
```

### 6.6 Personalização de Tema Não Existente
- "Ainda não temos um modelo pronto nesse tema, mas podemos desenvolver pra você!"
- Criar prévia do envelope para aprovação antes de prosseguir

### 6.7 Cliente Retorna Após Meses
- Verificar se houve mudança nos dados (data, horário, endereço)
- Cupom de desconto pode estar disponível

## 8. QUANDO ENCAMINHAR PARA HUMANO

A IA **NÃO DEVE** tentar resolver sozinha os seguintes casos:

### 8.1 Encaminhar Imediatamente

| Situação | Motivo |
|----------|--------|
| Solicitação de reembolso/cancelamento | Decisão financeira crítica |
| Reclamação séria sobre qualidade | Requer análise humana |
| Problema técnico complexo (bugs específicos) | Requer desenvolvimento |
| Pedido de prazo < 24h sem confirmação de disponibilidade | Verificar fila real |
| Negociação de preço fora dos padrões | Decisão comercial |
| Solicitação de serviços não listados | Avaliar viabilidade |
| Cliente agressivo ou insatisfeito | Comunicação delicada |

### 8.2 Mensagem para Encaminhamento
```
Vou verificar essa questão com minha equipe e já te retorno, tá bom? Só um momento!
```
